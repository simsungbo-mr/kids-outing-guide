GitHub Pages 배포 팁

1. 함께 제공된 ZIP 압축을 풀고 저장소 최상단에 올립니다.

2. Settings → Pages에서 Branch를 main / root로 저장합니다.

3. 매일 새 항목을 추가한 뒤 places.json만 덮어쓰면 완료!
